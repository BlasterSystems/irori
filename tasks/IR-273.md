## Objective

Show how the Sparks are cabled over RoCE, in what format, which nodes form
each cluster, live throughput and latency per link, and run throughput tests
on demand, on an Overview card. Make pushes use the fabric where it is direct.

## Product manager summary

- **One-liner:** an Overview Network card that maps the RoCE fabric live and tests it on demand.
- **User value:** the owner sees cabling faults, MTU mismatches and idle or saturated links without SSH, and pushes stop crawling over the 1 GbE LAN.
- **Business impact:** cluster serving depends on the fabric; problems become visible before they cost a failed NCCL start.
- **Success metric:** the card shows the real four-node ring with both lanes per cable; a test reports Gb/s per direction; a push between adjacent Sparks dials a 10.100.x address.
- **Dependencies & constraints:** RoCE fabric only (owner, 2026-11-27); NAS and LAN never drawn or measured.

- Tests: 63 new test cases across core/agent/server/web plus DB integration for both tables and the settings row.
- Documentation and ADRs: ADR 0021 Accepted (owner); amended before merge to record that perftest cannot bind its rendezvous socket.
- Adversarial review (`quality-review`, fresh read-only context):
  1. Pass 1 **BLOCK**: F1 (iperf3 listening line buffered on a pipe → every test fails), F2 (prober never re-arms after 0), F3 (generic job route bypasses the guards); U2/U3 unverified. All fixed in c2973ba with regression tests.
  2. Pass 2 (c2973ba) **BLOCK**: N1, a uutils `stdbuf` forks the tool, so a kill left it running. Fixed in 75a259c (process-group kill, real forking-wrapper test).

## Completion summary

- **Technical decisions:** topology derived, never stored; lanes grouped per node pair (two netdevs per CX7 cable here) and speeds not summed; live mode over SSE with a shared lease; tests as hub-sequenced jobs (ADR-0014 pattern); fabric pushes only for direct links, with a one-shot LAN fallback.
- **Known limitations:** IPv4 neighbours only (the fleet's fabric is IPv4); RDMA tests measure one direction (write); history samples every 10 s, so bursts shorter than that are averaged.
- **Deployment notes:** agents need the new bundle for link facts, prober, live mode and tests (update one worker first, then the rest); see the Deployment section for invariant and probe.
- **Follow-ups:** none filed yet; S6's after-throughput is recorded from the first real fabric push.
