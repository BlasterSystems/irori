# Task: IR-282 — Overview: adaptive Main+Rail layout + node-card declutter

Repo work item: **IRI-159** · Branch: `feat/iri-159-overview-main-rail` · Jira: [IR-282](https://blastersystems.atlassian.net/browse/IR-282) (In Progress, assigned bruno@blastersystems.com)

## Objective

Rework the Overview landing page into an adaptive Main + Rail layout and declutter the node card, per the approved research `tasks/research-overview-adaptive-layout.md` and mockup `mockups/overview-adaptive.html`.

## Product manager summary

- **One-liner:** The Overview page gets a 2fr/1fr Main+Rail shell (rail: token stats, NAS, clock caps, telemetry) and node cards drop repeated constants into tooltips.
- **User value:** No stretched cards, no 3+1 node orphan, constants one hover away; mobile keeps totals inline.
- **Business impact:** Landing-page usability for the homelab operator; no API/schema change.
- **Success metric:** 4-node fleet renders 2×2 with no orphan; page verified at 1296/1000/390 widths.
- **Dependencies & constraints:** Builds on IR-261 (1360px cap, Done); supersedes IR-224 S7 token-row placement (rationale in research doc).

## Acceptance criteria

- [ ] 4 spark nodes render as a 2×2 grid (no 3+1 orphan); 1–3 nodes render without waste (odd last card spans); NAS-only ghost unchanged.
- [ ] Node card head: no kind chip, no agent version, no inference line; constants reachable via tooltips (name = identity string; row labels = per-row details); drift chip still appears on drift.
- [ ] Thermal alert row renders only when a spark node ≥ 70 °C warn tier; hidden on healthy fleets.
- [ ] Rail contains token stats, NAS, clock caps, telemetry; Power + Updates full-width; shell stacks ≤1100; single column ≤900 with totals inline (touch fallback).
- [ ] `card-data.ts` line builders updated (pure functions, tests updated); web mount test for class bindings + tooltip content.
- [ ] `pnpm test` + `pnpm build` green.
