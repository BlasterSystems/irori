# Task: Overview — hero and Nodes render outside the Main+Rail shell

## Objective

Restore the approved IR-282 composition: the serving hero, the Nodes 2-col grid and the Power card all live in the shell's main column, so the rail (token stats · NAS store · fleet clock caps · telemetry) runs beside them from the top of the page. Today only Power is in the shell — the hero and node cards render as full-width bands above it (node cards ≈640px instead of ≈420px).

## Product manager summary

- **One-liner:** Move the hero section and the Nodes grid inside the Main+Rail shell's main column; move the Network card below the shell.
- **User value:** The Overview reads as designed at 1–4 nodes — compact node cards with breathing room, a used rail column instead of a half-empty one beside Power only.
- **Business impact:** Corrects a shipped defect against the owner-approved IR-282 design (reported by the owner 2026-11-27).
- **Success metric:** At full tier the main column is ≈2/3 width with ≈420px node cards; the rail is populated beside hero → nodes → power.
- **Dependencies & constraints:** None blocking. IR-282 (Done) delivered the shell; this fixes its scope.
